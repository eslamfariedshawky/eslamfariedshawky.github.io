# eslamfariedshawky.github.io

Redirects the old DualPrint (formerly MultiPrint) website address
`https://eslamfariedshawky.github.io/dualprinter/...` to
`https://eslamfariedshawky.github.io/dualprint/...`, keeping the rest of the path.

GitHub Pages does not redirect a project site after a repository rename, so this
user site serves the old path. Do not create a repository named `dualprinter`:
that would break GitHub's redirect from the old repository name.
